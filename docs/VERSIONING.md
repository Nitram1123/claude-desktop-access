# Versioning

Use the stable NVDA lineup. The first Claude Desktop Access version is **2026.2.1**, with minimum and declared last-tested NVDA compatibility **2026.2.0**. Advance the patch for subsequent packages. Do not advance the lineup for an NVDA alpha, beta or release candidate. Mark this add-on's beta status in the summary and GitHub prerelease flag, while retaining the requested numeric version.
